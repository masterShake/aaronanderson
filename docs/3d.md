# 3D

One WebGL canvas for the whole site, moved into whichever figure is most visible. Vanilla three
0.186.1, no React Three Fiber. The SVG drawing is always the first-class path; 3D is an
enhancement that hands off from it at a frame both renderers draw identically.

Only `src/stage/runtime/**` and `src/scenes/**` import three (ESLint enforces it, dynamic imports
included). The runtime holds the whole kit (`runtime/kit/index.ts`), so the kit and the Line2
family ship once, in the runtime group, and scene chunks carry only their own code.

## Tiers and loading

The head script owns `html[data-tier|data-tier-max|data-tier-force]`. The Stage never reads
`?tier` or reduced motion; it only:

- promotes `svg` to `webgl` with `setTier('webgl')` after a successful probe;
- downgrades the session with `downgrade(reason)` on a failed probe (`ineligible`), a context
  loss (`context-lost`) or the frame guard (`frame-guard`).

A scene whose `build()` or `update()` throws falls back for that figure only (`fallback` event
with `build-error`); it never downgrades the session. `FigureBoundary` does the same for React
errors.

Probe (`probe.ts`): WebGL2 with `failIfMajorPerformanceCaveat`, a software renderer
(SwiftShader, llvmpipe and friends), `deviceMemory < 4` and Save-Data all mean svg. A forced
`?tier=webgl` relaxes the caveat and software checks; the tests then assert a hardware renderer.

Load policy (each figure's `data-load`, D9):

| Policy    | Desktop                                              | Touch (`pointer: coarse`)    |
| --------- | ---------------------------------------------------- | ---------------------------- |
| `hero`    | after `load`, then idle (timeout `LOAD.idleTimeout`) | after `load` and 30% visible |
| `near`    | after `load`, figure within one viewport             | after `load` and 30% visible |
| `visible` | after `load` and 30% visible                         | after `load` and 30% visible |

On touch nothing is probed or fetched before that. Each scene is built only when its figure comes
within one viewport. `HERO_TOUCH_3D = 'deferred'` keeps the hero SVG on touch.

Ship gates: a scene marked `'svg'` in `gates.ts` never registers 3D. Outside production,
`?ship=s04` (comma-separated) or `?ship=all` treats those scenes as `'webgl'`.

## Figures

Figures use `useFigure(id, { stage: { scene, load, mode } })`, which calls `bindStage`. The
handle (`FigureHandle`) is the only way to talk to the Stage:

- `markRest('decision' | 'boundary', loop)` → `requestHandoff`; `false` means run the SVG path.
- `setProgress(p)` forwards raw scrub progress; scrub figures hand off when raw p enters
  `[pH, pH + 0.04]` and hand back when raw p < pH − 0.01 and smoothed p ≤ pH + 0.005. pH comes
  from `data-handoff-p` on the figure, else the `--<scene>-handoff-p` timing variable
  (`cssVars(S02, 's02')` writes it).
- Events: `ready` (compiled and two GPU fence syncs signalled at opacity 0), `handoff` (after the
  120 ms cross-fade), `handback`, `beat`, `fallback` (with `atMs`, the mechanism time to resume
  the SVG path at).

The Stage writes `data-stage` (svg, handoff, webgl, handback) and `data-labels` on the figure, and
`--ix`/`--iy` on `.labels [data-anchor="key"]` spans from the scene's projected anchors. CSS
hides the CAD layers under `[data-stage=webgl]`. The canvas and the still carry their own inline
styles, so they work under any figure CSS.

## Scenes

A scene exports `create(ctx) → SceneInstance` (`src/stage/types.ts`). Rules:

- Pose 0 (`reset()`) must draw exactly the figure's SVG frame (`drawings/lib/frame.ts`):
  `OrthoRig('plan' | 'front')` maps SVG (x, y) to world (x, 0, y) (or the front elevation), the
  frustum is the CSS box, and the viewBox sits in it as `xMidYMid meet`.
- Line widths: `ctx.strokePx(pen)` = pen × `--k` × CSS px per unit; set them again in `resize()`.
- Faces use `withFlatMix(material)` so they are the exact panel tone until they anodize.
- No zero-length line segments (vertical edges project to points in plan: keep them hidden there).
- `build()` yields after each unit of ≤4 ms; the runtime slices at 8 ms.
- `dispose()` frees geometries and non-shared materials (`userData.shared` marks the session's).
- No text in the canvas; labels are HTML.

`src/scenes/_demo.ts` on `/kit/stage` exercises extrusions, pipes, packets and a gauge through the
whole hand-off; its plan lives in `src/app/kit/stage/demo-plan.ts`, drawn by both renderers.

## Runtime behaviour

- One renderer per session on the probe's context (one context total); NeutralToneMapping,
  sRGB output, transparent canvas over the CSS panel.
- The canvas moves into the most visible candidate (≥10% visible; switch when another is 15
  points more visible; never during a cross-fade). The figure being left gets a `drawImage` still
  in the same task; stills more than two viewports away are released.
- DPR: ≤2 on desktop; touch 2 if the backing store at 2× is ≤0.75 MP, else 1.5; the frame guard
  can cap it at 1.
- The loop runs only while something animates. Off-screen (<10%), a hidden tab, or
  `html[data-motion=paused]` (unless the figure has `data-user-play`) stop it.
- Frame guard: skip 5 frames, median of the next 60; over 20 ms drop DPR to 1, still over 20 ms
  fall back to SVG and downgrade the session.
- Context loss: every figure falls back at once (well under 500 ms), the session is downgraded,
  and the Stage never re-enters WebGL on that page.
- `release()` is idempotent; disposal waits a turn, so StrictMode's remount keeps the scene.
  After 30 s with no figure the renderer, env and shared materials go too.
- Env: RoomEnvironment through PMREM, once per session, size `ENV.size` (128).

Perf marks: `3d:init`, `3d:first-frame`, `3d:env`, `3d:build:<id>`, `3d:compile:<id>`,
`3d:ready:<id>`, `3d:handoff:<id>`.

## Debug (not in production)

`window.__aeStage`:

- `state()`: renderer string, tier, frames, guard, `renderer.info.memory`, every figure's state,
  and the ship map.
- `holdAtHandoff(scene)`: waits for `ready`, then freezes the scene at its hand-off frame.
- `show(scene, 'svg' | 'webgl')`: toggles the canvas and the CAD layers for screenshots.
- `seek(scene, { ms } | { p })`: freezes the scene at a time or a scrub progress.
- `loseContext()`: forces a context loss.

`?frame=plan` holds the first stage figure at its hand-off frame.

pass. Add a scene's figure to `SCENES` in `e2e/seam.spec.ts` to put it through the seam test.
