# 3D

_Skeleton from W0; the stage lane completes it._

- One WebGL canvas for the site, moved into the most visible figure. Figures use
  `stage.register()` from `src/stage/host.ts`; the API is frozen in `src/stage/types.ts`.
- Only `src/stage/runtime/**` and `src/scenes/**` import three (ESLint enforces it).
- `src/stage/gates.ts` decides which scenes ship as WebGL (`SHIP`) and whether phones build the
  hero in 3D (`HERO_TOUCH_3D`).
- `src/scenes/_probe.ts` imports the whole planned three subset; `/kit/stage?probe=1` loads it
  so its chunk size can be measured.
